# Masu 検証報告

2026年11月22日。Apple Silicon macOS上で実施。

## 実装した範囲

React・TypeScript・ViteでWebアプリを新規実装した。加算、減算、乗算、除算に共通の盤面と入力順を使用する。桁上がり、0を経由する借り入れと斜線、部分積、商、下ろす数、余りを扱う。乗除算の小数、除数の整数化、有限小数の商にも対応した。

ホームの演算選択、難易度、詳細桁数、5／10／20問、3数の加算、余りの条件、ナビON/OFF、前後移動、消去、ヒント・答え表示、採点・誤答修正、結果比較、復習、保存と再開、削除確認を実装した。

保存領域はアプリ専用キーを使用する。破損データを検証して処理し、保存不可時は画面内の練習を継続する。履歴は直近30セッションかつ最大100問とした。初回採点と修正後の正解を区別する。

アイコンは新しい格子と加算記号をSVGで制作した。1024px PNGと16～1024pxのICNS画像を生成した。旧アプリからのコード・画像・SDKのコピーは行っていない。

## 発見して修正した不具合

- 小数点が最後の手順の場合に採点ボタンが使えなかった。小数点入力を独立させ、確認ボタンを常時配置した。
- SVGの標準画像変換が失敗したため、AppKitで1024px PNGを作成する方式に修正した。
- ICNS生成の失敗を、PNG画像から正規ICNSチャンクを組み立てる再現可能な処理で修正した。macOSのiconutilで再展開できることを確認した。
- Finderが設定を保存してもcustomIconプロパティがnilを返す環境だった。設定APIの戻り値と実際のIconリソースを検証する処理へ修正した。
- 開発用Lintパーサーの推移依存に中程度の脆弱性を検出した。パーサーを修正版8.73.0へ限定更新し、再監査で0件を確認した。
- 履歴の復習問題数を100問までに制限し、対応する回帰テストを追加した。

## 筆算手順・配置の修正

2026年11月22日の追加修正。

- 掛け算は部分積をすべて入力した後、加算記号と下線の下にある答えの行で各位の和を入力する。案内に「最後の足し算」を表示し、乗数が1桁でも最後の加算段階を設けた。
- 割り算の借り入れ・借り元の数字を、引かれる数の上に配置する。商はさらにその上に置き、補助マスとの重なりを避ける。
- 割り算の各段に減算記号を表示する。次の数字は直前の差と同じ行の右隣に、元の数字と列をそろえて下ろす。
- 旧版の1桁乗算の保存記録は、新しい加算段階へ移行する。既存の入力・初回採点・履歴を保持する。
- 単体試験は28件に拡張し、最終加算への入力順、201÷13の借り入れと下ろす位置、既存記録の移行を検証した。

## 割り算の表示構造と目視検証の再修正

220÷6の利用者スクリーンショットを基準に、商・補助記号・途中計算の表示を修正した。

- 商、被除数、積、差、下ろす数字を連続する主行に配置した。繰り下がりと乗算の繰り上がりは、対象数字の上に小さいメモとして配置する。
- 割り算の括弧と上線をCSSの罫線で接続した。「余り」は2桁分の幅を確保して1行で表示する。
- ナビONでは未着手の計算段を隠す。ナビOFFと結果の比較画面では全段を表示する。
- 入力済みの誤答は採点前にも枠で示し、自動移動は維持する。
- 有限小数へ拡張する際、補った0に対応する被除数の小数点を表示する。
- 計算手順と保存データの配列順は維持した。メモの表示位置を入力手順から分離している。

専用のブラウザ試験を tests/division-browser.mjs に追加した。220÷6を「3→1→8→1→1→4→0→6→3→6→1→3→4→4」と手入力し、36余り4で正解することを確認した。4と下ろす0の行位置、桁間隔44px、補助メモの寸法、引き算の行間、括弧の罫線、「余り」の幅、誤答の印をブラウザで測定した。

## 割り算の繰り下がり省略と小数の開始画面

割り算内の引き算では、借りた1、借り元の数字、斜線を生成せず、計算した差を直接入力する仕様へ変更した。通常の引き算では繰り下がり手順を維持する。

739.0÷5.0の開始画面には、元の式が商の行に見える配置、まだ必要のない補充0と小数点の先行表示、将来の桁による横幅拡大があった。元の式は画面タイトルに表示し、筆算内には「7390÷50にして計算」という整数化の説明と実際の入力対象を表示する。商・補充0・補充小数点は必要な手順に到達してから表示し、開始時の幅は表示中の桁から計算する。

tests/decimal-browser.mjsで開始時、整数化直後、完答までを操作した。739.0÷5.0=147.8、12.5÷5=2.5、0.12÷0.3=0.4、1.2÷0.03=40が成功。739.0÷5.0の開始画面と整数化直後は画像でも確認した。
