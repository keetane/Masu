# Masu 検証報告

2026年11月22日。Apple Silicon macOS上で実施。

## 実装した範囲

React・TypeScript・ViteでWebアプリを新規実装した。加算、減算、乗算、除算に共通の盤面と入力順を使用する。桁上がり、0を経由する借り入れと斜線、部分積、商、下ろす数、余りを扱う。乗除算の小数、除数の整数化、有限小数の商にも対応した。

ホームの演算選択、難易度、詳細桁数、5／10／20問、3数の加算、余りの条件、ナビON/OFF、前後移動、消去、ヒント・答え表示、採点・誤答修正、結果比較、復習、保存と再開、削除確認を実装した。

保存領域はアプリ専用キーを使用する。破損データを検証して処理し、保存不可時は画面内の練習を継続する。履歴は直近30セッションかつ最大100問とした。初回採点と修正後の正解を区別する。

アイコンは新しい格子と加算記号をSVGで制作した。1024px PNGと16～1024pxのICNS画像を生成した。旧アプリからのコード・画像・SDKのコピーは行っていない。

## iPhoneからのLAN利用

ランチャーの待受を127.0.0.1と、en系インターフェースで検出したプライベートIPv4へ拡張した。MacのブラウザはLAN用URLで開く。アプリメニューにiPhone用アドレスの表示・コピーと、以前のローカルアドレスを開く操作を追加した。

二つのアドレスで同じポートを使う際に発生した初期起動の競合は、NWParameters.allowLocalEndpointReuseを設定して修正した。lsofで実際の待受が127.0.0.1とLANの個別IPv4アドレスだけであることを確認した。IPv6やワイルドカードの待受は行っていない。Hostはこれらのアドレスとlocalhostだけを受け付け、未知のHostでは404になることを確認した。ルーターやOSのファイアウォール設定は変更していない。

LANのHTTPではcrypto.randomUUIDが使えないため、crypto.getRandomValuesを使ったUUIDの代替処理を追加した。実際に安全なコンテキストでないLAN URLへ接続し、練習の開始・保存・再読み込みが動くことをChromeで検証した。

## 乗数が1桁の場合の最終加算の省略
