# Masu

**無料で使える、四則演算の筆算練習アプリです。** iPhone・スマートフォン・PCのブラウザで、数字を順番に入力しながら計算の手順を学べます。アカウント登録は不要です。

**[Masuを使う](https://keetane.github.io/Masu/)**

## できること

- たし算・ひき算・かけ算・わり算の練習
- 難易度、桁数、問題数の設定、かけ算・わり算の小数問題
- 次に答える位置を示すナビゲーションと、繰り上がり・繰り下がりの練習
- 小数のわり算で、除数・被除数の小数点を順番に動かす操作
- ヒント、採点、答えの修正、結果の確認と復習
- 途中の練習と履歴のブラウザ内保存
- スクショを選んで状況を書ける不具合報告メニュー
- 日本語・英語の表示切替（画面上部の日本・米国の国旗アイコン）

乗数が1桁のかけ算は積を入力すれば完了し、2桁以上では部分積を計算してから最後に足し合わせます。わり算の中の引き算は、繰り下がりの補助入力を省いて進めます。

## 使い方

1. ホームで演算、難しさ、問題数を選び、「はじめる」を押します。
2. 必要なマスは最初から全て表示されます。入力先は濃く、計算に使う数字は薄く強調されます。濃いマスに数字を入力します。「ナビ ON」では次の入力先へ自動で移動します。
3. 全て入力すると右下の「確認」が「採点」に変わります。採点後は同じボタンが「次へ」（最後の問題は「結果を見る」）になり、不正解でもそのまま進めます。
4. 「× 不正解数」を押すと間違いへ移動できます。結果の問題別○×からも、計算の手順を見直せます。

ブラウザで動くWebアプリです。インストールせず、上のリンクから利用できます。macOS用ランチャーや開発方法は[開発・ローカル配布ガイド](docs/DEVELOPMENT.md)を参照してください。

言語の選択は次回も引き継ぎます。練習途中に切り替えても、入力した数字や履歴は保持されます。English is available using the US flag at the top of the page.

## 保存とプライバシー

設定、途中の回答、直近30回・最大100問の記録を、利用しているブラウザ内に保存します。端末間の同期はありません。ブラウザのサイトデータを消去すると記録も消えます。

現在の版に広告・アクセス解析はなく、学習記録を自動でサーバーへ送信する機能もありません。不具合報告で選んだ画像・報告文は、自分の操作でGitHubや共有先へ渡せます。Web配信元はページ取得に伴う接続情報を処理する場合があります。[プライバシーについて](docs/PRIVACY.md)も確認してください。
